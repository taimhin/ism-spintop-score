# ISM 初中組陀螺大賽 — 計分系統

單一 HTML 檔的陀螺比賽計分網站（單淘汰、先取 4 分、含季軍賽）。

## 使用方式

- 線上版（公開網址）：https://taimhin.github.io/ism-spintop-score/
- 離線版：下載 `index.html`，用 Chrome / Edge 雙擊開啟即可，不需網路、不需要安裝任何東西。

## 功能

- **對陣圖**：64強資格賽 → 32強 → 16強 → 8強 → 4強 → 決賽＋季軍賽；點任一場比賽跳到記分板。
- **記分板**：點選手區塊 +1 分，先得 4 分自動判定勝出並晉級下一輪；可「減 1 分」「重設此場」「下一場」。
- **名次**：即時顯示冠 / 亞 / 季 / 殿軍，可列印成績表、匯出 CSV、匯出 JSON 備份。
- **分享連結**：按「🔗 複製分享連結」，會把目前比分編碼在網址中；別人打開連結就會看到相同的比分。
- **自動儲存**：資料存在瀏覽器本機（localStorage），重新整理不會遺失。

## 注意

- 因為是靜態網站，**每台裝置的資料各自保存**。要讓別人看到你的最新比分，請用「分享連結」功能，或把最新的 JSON 備份傳給對方匯入。
- 選手名單、比賽名稱、先取分數都可以在「設定」頁修改。

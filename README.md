# ISM 初中組陀螺大賽 — 計分系統

單一 HTML 檔的陀螺比賽計分網站（單淘汰、先取 4 分、含季軍賽）。

## 三種使用方式

1. **線上版（推薦）**：https://taimhin.github.io/ism-spintop-score/
   - 朋友打開同一條網址就能**一起看、一起改比分**；任何一台裝置記分，全部裝置即時同步（約 1 秒內）。
   - 免登入、免帳號，只需要網路連線。
2. **場地主機模式（沒網路的場合）**：見下方說明；同一 Wi-Fi 內即時同步。
3. **離線單機**：下載 `index.html` 直接開啟；不會同步。

## 同步與隱私注意

- 線上版的同步是透過公共 MQTT 伺服器（HiveMQ / EMQX / Mosquitto）的隨機頻道進行。
- **任何拿到網站網址的人都可以修改比分**（這是刻意設計，方便一起記分）；請不要把網址公開貼到太公開的地方。
- 網址參數：`?lan` 強制場地主機模式、`?cloud` 強制雲端模式、`?local` 完全單機。

## 場地主機模式（無網路備用）

讓多台裝置在同一 Wi-Fi 內即時同步比分：

1. 在計分用的電腦安裝 Python 3（[python.org](https://www.python.org/)）。
2. 把 `index.html` 和 `server.py` 放在同一個資料夾。
3. 在該資料夾執行 `python server.py`（Windows 也可以做 .bat 雙擊執行）。
4. 視窗會顯示網址與 QR Code：
   - 主機電腦：`http://localhost:8000`
   - 其他裝置：`http://192.168.x.x:8000`（連同一個 Wi-Fi 即可打開）
5. 資料自動存在 `state.json`，主機關掉再開不會不見。

> 第一次啟動時，Windows 防火牆請按「允許存取」，其他裝置才連得進來。

## 功能

- **對陣圖**：64強資格賽 → 32強 → 16強 → 8強 → 4強 → 決賽＋季軍賽；點任一場比賽跳到記分板。
- **記分板**：點選手區塊 +1 分，先得 4 分自動判定勝出並晉級下一輪；可「減 1 分」「重設此場」「下一場」。
- **名次**：即時顯示冠 / 亞 / 季 / 殿軍，可列印成績表、匯出 CSV、匯出 JSON 備份。
- **分享連結**：按「🔗 複製分享連結」，把目前比分編碼在網址中；別人打開連結就會看到相同的比分快照。
- **即時同步**：線上版顯示「☁️ 雲端同步中」；場地主機顯示「🟢 場地同步中」。
- **自動儲存**：資料存在瀏覽器本機（localStorage），重新整理不會遺失。

## 自訂

- 選手名單、比賽名稱、先取分數都可以在網站「設定」頁修改（改動會同步給所有裝置）。
- 想換同步後端（例如 Firebase、Supabase）或改成唯讀分享，可以再修改 `index.html` 內的同步模組。

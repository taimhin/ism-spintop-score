# ISM 初中組陀螺大賽 — 計分系統

單一 HTML 檔的陀螺比賽計分網站（單淘汰、先取 4 分、含季軍賽）。

## 使用方式

- **線上版（靜態）**：https://taimhin.github.io/ism-spintop-score/
- **場地即時同步版（推薦比賽當天用）**：見下方說明
- **離線版**：下載 `index.html`，用 Chrome / Edge 雙擊開啟即可，不需網路。

## 即時同步（場地主機模式）

讓多台裝置即時同步比分：一部電腦當主機記分，其他手機 / 平板打開網址就會自動看到最新比分。

1. 在計分用的電腦安裝 Python 3（[python.org](https://www.python.org/)）。
2. 把 `index.html` 和 `server.py` 放在同一個資料夾。
3. 在該資料夾執行 `python server.py`（Windows 也可以做一個 .bat 雙擊執行）。
4. 視窗會顯示網址：
   - 主機電腦：`http://localhost:8000`
   - 其他裝置：`http://192.168.x.x:8000`（連上同一個 Wi-Fi 即可打開）
5. 所有人打開網址後，任何一台記分，其他裝置 2 秒內自動更新。
6. 資料自動存在 `state.json`，主機關掉再開也不會不見。

> 第一次啟動時，Windows 防火牆請按「允許存取」，其他裝置才連得進來。

## 功能

- **對陣圖**：64強資格賽 → 32強 → 16強 → 8強 → 4強 → 決賽＋季軍賽；點任一場比賽跳到記分板。
- **記分板**：點選手區塊 +1 分，先得 4 分自動判定勝出並晉級下一輪；可「減 1 分」「重設此場」「下一場」。
- **名次**：即時顯示冠 / 亞 / 季 / 殿軍，可列印成績表、匯出 CSV、匯出 JSON 備份。
- **分享連結**：按「🔗 複製分享連結」，把目前比分編碼在網址中；別人打開連結就會看到相同的比分（線上版適用）。
- **即時同步**：場地主機模式下，所有裝置比分自動同步（頁面上會顯示「🟢 即時同步中」）。
- **自動儲存**：資料存在瀏覽器本機（localStorage），重新整理不會遺失。

## 注意

- 線上版（GitHub Pages）是靜態網站，**各裝置資料各自保存、不會自動同步**；要即時同步請用場地主機模式。
- 選手名單、比賽名稱、先取分數都可以在「設定」頁修改。
